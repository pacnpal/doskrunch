# Tier decompression benchmark

Synthetic mixed-content payload: 500 KiB (512000 bytes) — text + zeros + LCG-random + repeated patterns. See `host/tests/benchmark_tiers.rs::synthesize_payload` for the exact distribution.

Measurement setup:

* Isolated decode time: the stub wraps each `aplib_depack` call with `INT 1Ah` (`AH=00h`) and writes `DKPERF.BIN` (little-endian `u32` total decode ticks) in benchmark runs. `INT 1Ah` ticks run at ~18.2 Hz and are available on every target tier (8086+).
* End-to-end wall-clock: host-side timer around the full DOSBox run (`cycles=auto`), min across 3 runs.
* Benchmark gating: `#[ignore]` AND env-var-gated (`DOSKRUNCH_RUN_BENCHMARK=1`) so CI's `--ignored` run doesn't silently rewrite this file.

```bash
DOSKRUNCH_RUN_BENCHMARK=1 SDL_VIDEODRIVER=dummy cargo test --test benchmark_tiers -- --ignored --nocapture
```

## Caveats

* `INT 1Ah` has coarse resolution (~54.9 ms/tick), so small payloads are noisy. The 500 KiB payload keeps decode long enough to make ratios stable.
* `INT 1Ah` wraps at midnight. This harness only times single decode calls that run for seconds, so unsigned tick-delta arithmetic is safe.
* Wall-clock and decode-time are both useful: the decode ratio tracks `aplib_depack` itself; wall-clock still reflects user-visible elapsed time including DOS startup and INT 21h file I/O.
* The benchmark is double-gated (`#[ignore]` + `DOSKRUNCH_RUN_BENCHMARK=1`); CI's `cargo test --workspace -- --ignored` run skips it via the env-var check, so this file is only regenerated by a local opt-in run. Commit a refreshed copy when the numbers move.
